EZprogramming language

Write a script. Ship an .exe.

EZ is a small, fast scripting language for Windows. It reads like plain English, has a native GUI, SQLite and async built in, and bundles into one file you can hand to anyone.

A language you can learn in an afternoon

EZ keeps the keyword list short (46 in total) and puts the tools you usually hunt for into the box.

Readable keywords
task declares a function, give returns, when / other branch. yes and no work as booleans.
Fast bytecode VM
A stack VM with computed gotos, a cycle-collecting garbage collector and tail-call optimization.
Native Windows GUI
More than 60 built-in controls: windows, canvas drawing, buttons, sliders, list views and dialogs. No web runtime.
One-file distribution
ez bundle packs your script and its libraries into a single self-extracting executable.
Concurrency that works
async / await on a libuv event loop, OS threads with spawn, plus Mutex, Atomic and Go-style Channel.
Safe by default
Run untrusted code with --safe and grant only the file, network or FFI access it needs. C FFI calls are guarded against access violations.

What is in the box

    
Most small programs need nothing outside the standard library.

    

      
Math
Trigonometry, logarithms, clamp, hypot, random numbers, and bitwise operators on 64-bit integers.

      
Strings and regex
Template strings, split, replace, padding, Base64 URL encoding, and re_find, re_replace and re_test.

      
Collections
Arrays, dictionaries and tuples with map, filter, reduce, find, sort and range, plus JSON and CSV parsing.

      
Files and I/O
A stream-based File class, whole-file helpers, and the fs module for folders.

      
Database
Embedded SQLite through use "sqlite", and a @persist decorator that saves model changes automatically.

      
Security
Ciphers and hashes through use "crypto", plus the permission sandbox for untrusted scripts.

      
Network
HTTP and socket builtins, with NetworkError and TimeoutError for failures.

      
Terminal apps
Terminal and TUI builtins for interactive command-line tools.

      
Binary data
A Buffer class for raw bytes, handy for file formats, protocols and FFI structures.

      
Reflection
properties, hasattr, getattr and setattr inspect any object at runtime.

    

  


  

    
Small language, serious engine

    
EZ is written in C++17. A single-pass compiler turns your code into bytecode for a stack VM.

    

      

        
Built for speed

        
Moving from a tree-walking interpreter to a bytecode VM with computed gotos made EZ about 40 times faster. Global variable slots, superinstructions and hidden-class object shapes cut overhead further, so a 100,000-iteration loop runs in a few milliseconds, close to CPython.

        
Memory is managed by a cycle-collecting garbage collector, and the event loop runs on libuv.

      

      

        
Native on Windows

        
Build desktop apps with real Win32 controls: windows, canvas 2D graphics, buttons, sliders, list views and dialogs. Bundle with --gui and the app opens with no console window.

        
When you need more, the C FFI loads any DLL, behind a permission flag and structured exception handling.

      

    

  


  

    
From first line to a file you can send

    
The interpreter, package manager and bundler are one self-contained ez.exe.

    

      
run & develop


# Run a script, or open the REPL
ez main.ez
ez

# Re-run on every save
ez --watch main.ez

# Built-in test runner
ez test my_tests.ez

      
bundle & secure


# Console app
ez bundle main.ez MyApp.exe

# GUI app with an icon
ez bundle main.ez App.exe --gui --icon app.ico

# Sandbox: allow only what is needed
ez --safe --allow-read=data main.ez

Questions

    
Do people need to install EZ to run my program?
No. ez bundle packs your script, its libraries and the runtime into one executable that runs on its own.

    
Is EZ typed?
Types are optional. You can add type hints and a type checker will use them, but the hints are erased at runtime. Turn the checker off with --no-typecheck.

    
Can EZ call C libraries?
Yes. The FFI loads native libraries and calls them directly. It needs --allow-ffi when you run in the sandbox.

    
Which platforms does it support?
EZ started as a Windows-native language, and the interpreter now builds and passes its tests on macOS and Linux too. The Win32 GUI is Windows only.

    
Is it open source?
Yes, under the MIT license. Issues and pull requests are open on GitHub.

    
How do I install EZ on Windows?
Run winget install imabd645.EZ in a terminal, then check it with ez --version. You can also download ez.exe from GitHub Releases and add it to your PATH.

    
How do I update EZ?
If you installed with winget, run winget upgrade imabd645.EZ. If you downloaded ez.exe by hand, replace it with the newest release.

    
What do EZ files look like?
Source files end in .ez. Precompiled bytecode uses .ezc, and ez --dump writes a readable listing as .ezasm.

    
Does EZ have a database?
Yes. SQLite is built in through use "sqlite", and the @persist decorator can write a model’s changes straight to a database file.

    
How does error handling work?
Use try, catch and finally with typed catch clauses. All 21 native errors descend from Exception, and you can extend it with your own error models.

    
Can I run things in parallel?
Yes. Use async and await for futures, spawn for OS threads, and Mutex, Atomic and Channel to coordinate them.

    
How do I test my code?
Write test "name" { ... } blocks with assert, then run ez test file.ez. Add --watch to rerun them on every save.

    
Is it safe to run someone else’s script?
Run it with --safe so it can only touch what you allow. ez permissions script.ez lists the access a script asks for before you run it.

    
How do I share a library?
Publish it to the ezlib registry at packages.ez-lang.site. The package manager checks SHA-256 hashes when it installs.

    
Should I use EZ instead of Python?
It depends on the job. EZ suits small tools, desktop apps and programs you want to hand over as one .exe. Python has a far larger ecosystem, so pick it when you need those libraries.

    
How can I help?
Open an issue or a pull request on GitHub, publish a package, or share an example program.
